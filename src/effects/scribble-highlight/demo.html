Scribble it like you meant it

Six separate crayon drawings, cycled on twos. Every boil frame is redrawn from scratch rather than wobbled, so the outline crawls the way rough animation does — then it breaks up and leaves.

Live

flutterOut is on here, so the drawing erases itself a couple of beats after it lands. Hit Replay to run the draw-on again.

Variants

Seven base geometries, each roughened by the same hand. The wall runs with flutterOut: false so you can sit and watch the boil.

Scrubbed by scroll

trigger: 'scroll' maps scroll position onto the whole timeline: the line draws on as the target rises, holds, then flutters off as it leaves.

Trace a subject

The reference shot: a hand-authored polygon in the still's own box space, scribbled around the dog and scrubbed by scroll. trace takes points as 0..1 pairs, so the same outline holds at any size.

Usage

import { createScribbleHighlight } from './effects/scribble-highlight';
import './effects/scribble-highlight/effect.css';

const claim = document.querySelector<HTMLElement>('#claim')!;

const handle = createScribbleHighlight(claim, {
  variant: 'circle',
  color: 'var(--amber)',
  strokeWidth: 4,
  frames: 6,
  fps: 12,
  jitter: 5,
  passes: 2,
  trigger: 'inview',
  duration: 700,
});

handle.setOptions({ variant: 'underline' });
handle.replay();

// Trace a subject inside a still: points are 0..1 in the target's own box.
const shot = document.querySelector<HTMLElement>('#shot')!;

createScribbleHighlight(shot, {
  variant: 'trace',
  color: 'var(--amber)',
  strokeWidth: 5,
  padding: 0,
  trigger: 'scroll',
  scroll: { start: 0.85, end: 0.5 },
  flutterOut: false,
  path: [
    [0.532, 0.067],
    [0.686, 0.291],
    [0.762, 0.847],
    [0.504, 0.999],
    [0.395, 0.46],
    [0.446, 0.145],
  ],
});

handle.destroy();
