Transition

Film burn transition

The outgoing shot catches, holes open where the heat finds the emulsion first, and the incoming shot is already behind it. Nothing here is pre-rendered: the burn field is generated live, either as a fragment shader or as a thresholded SVG turbulence filter.

Usage

import './effects/film-burn-transition/effect.css';
import { createFilmBurnTransition } from './effects/film-burn-transition';

// The host is the scroll length; the effect pins the picture inside it.
const burn = createFilmBurnTransition(document.querySelector('#burn'), {
  from: '/media/shot-a.jpg',
  to: '/media/shot-c.jpg',
  renderer: 'auto',
  origin: 'center',
  edge: 0.06,
  scale: 3,
  grain: 0.35,
  seed: 1,
});

burn.activeRenderer; // 'webgl' or 'css'

// Drive it yourself instead of by scroll.
burn.setOptions({ scroll: false });
burn.setProgress(0.5);

burn.destroy();

Every option is documented in src/effects/film-burn-transition/README.md, including what the CSS renderer gives up.
