Disintegration

Particulate dissolve

A surface breaks into ash, shears along a noisy edge, and drifts out of the frame. Scroll in either direction: every fleck is reconstructed from its seed and progress, so the same point in the scrub is always the same frame.

Field note 06

The weather kept the evidence.

This is selectable text, emphasis, and a real link inside the effect. The CSS renderer thresholds one static turbulence field over the live markup; the canvas only carries the ash that has detached.

Nothing was rasterised to make this disappear.

Media · renderer switch

The media side requested auto and is currently using …. The live-markup side always uses CSS/SVG because a WebGL canvas cannot sample arbitrary DOM.

Usage

import './effects/particulate-dissolve/effect.css';
import { createParticulateDissolve } from './effects/particulate-dissolve';

// Omit src to dissolve selectable text and arbitrary live markup.
const copy = createParticulateDissolve(document.querySelector('#article'), {
  renderer: 'css',
  direction: 'up',
});

// Media can use the per-pixel WebGL upgrade when WebGL2 is available.
const image = createParticulateDissolve(document.querySelector('#still'), {
  src: '/media/shot-a.jpg',
  renderer: 'auto',
  grain: 6,
  seed: 1,
});

image.activeRenderer; // 'webgl' or 'css'

// Manual scrubbing is deterministic in either direction.
image.setOptions({ scroll: false });
image.setProgress(0.6);
image.setProgress(0.3);
image.setProgress(0.6);

copy.destroy();
image.destroy();
