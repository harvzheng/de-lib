Street Light

One lamp on a wire, standing still. Scroll, and the page walks underneath it: the heading, the paragraph and the photograph below each go dark, then lit, then dark again as they pass through the pool on the ground. The lamp never moves — you do.

He flips the coin and waits for the bus

Nothing on this page is a copy of itself sitting under a coloured disc. The darkness is a blue-grey multiply with a hole in it, and the light is a warm screen and overlay through that same hole, so the pixels being brightened are the ones you are reading.

Then out of it again, and the street closes over

Text stays text. This paragraph is selectable, searchable and read out in order, because the effect never touches the host's own markup — it appends aria-hidden layers that take no pointer events and blend against whatever the host already painted.

The lamp is drawn too: a mast off the top of the frame, an arm reaching in, and a head with a hot lens. The hardware is dark metal; the only bright thing about it is light the screen layer adds, so turning the lamp down leaves a silhouette rather than a glowing sticker.

Progress: 0.000 — scroll-driven by default. Turn off Scroll-driven in the controls and the Progress slider walks the page under the lamp by hand, which lands the light in exactly the same place a real scroll would. It is the quickest way to compare one element lit against the same element dark.

Drop it over content you already have

The host keeps its own background, text and images; the lamp lights them. It wants content with somewhere to fall from and somewhere to rise to — a dark-but-not-black ground, a photograph, a video — since multiplying night onto near-black has nothing to take away and screening light onto white has nothing to add. 

import './effects/street-light/effect.css';
import { createStreetLight } from './effects/street-light';

const lamp = createStreetLight(host, {
  anchor: 0.26,     // the lamp's line, as a viewport fraction
  column: 0.4,      // where it stands across the host
  light: '#ffc27a', // sodium; '#f2f6ff' for LED
  night: '#4a5c80', // night is blue, not black
});

// Drive it yourself instead of by scroll.
lamp.setOptions({ scroll: false, progress: 0.35 });
lamp.setProgress(0.62);

lamp.destroy();
