Film Burn Overlay

A sustained burn-and-light-leak layer over a single image: holes bloom open and stay charred, embers crawl and flicker, light leaks sweep and drift, and the frame breathes as you scroll through it. Think of a strip of film that sat too long in the gate, not a cut between two shots.

Scroll to burn it

Drop it over an image

Give it a host element containing an <img> and it treats that image in place — no wrapper markup, no second copy of the picture. 

import './effects/film-burn-overlay/effect.css';
import { createFilmBurnOverlay } from './effects/film-burn-overlay';

const effect = createFilmBurnOverlay(host, {
  intensity: 0.7,
  leak: 0.6,
  holes: 4,
});

// Later — on unmount, route change, or teardown.
effect.destroy();
