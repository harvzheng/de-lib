Overlay — WebGL, with a CSS gradient renderer

Bokeh

Defocused highlights sitting in front of the page. The discs are not scattered at random: the effect reads the picture once, finds the bright isolated points in it, and puts a disc on each one, carrying that point's colour and brightness. A lamp becomes a lamp-shaped bokeh, a dim reflection becomes a dim disc, and the field belongs to the frame instead of sitting on top of it. Scrolling makes them shimmer.

Placed on the picture, not over it

… of the discs are sitting on a highlight detected in the photograph above — the blown-out background, the reflections, the gaps in the crowd. Pull Follow highlights down to zero in the control rack and the same discs scatter into a free field, which is also what you get when there is no readable source: no media in the host, or a cross-origin image the canvas cannot read.

A disc that sits on a highlight stays on it — a lamp does not slide across the frame because you scrolled — so the scroll response there is the shimmer, while free discs also drift. This paragraph is real text under the same overlay: no screenshot, no canvas copy of the page.

Currently rendering with …. The WebGL path draws each disc per pixel, so it is the one that can cut real aperture blades and fringe the rim; the CSS path paints one gradient element per disc from the same list, so both agree on where every disc is.

Drop it over anything

The host can hold an image, a video, or live text. Detection reads the first <img> or <video> inside the host once, on mount and on resize — never per frame. The overlay is aria-hidden and never takes pointer events. 

import './effects/bokeh/effect.css';
import { createBokeh } from './effects/bokeh';

const effect = createBokeh(host, {
  renderer: 'auto',
  source: 'auto',   // or an element, a selector, or 'none'
  follow: 0.9,      // 0 scatters the discs instead
  count: 20,
  size: 0.16,
  softness: 0.7,
  shimmerRate: 7,
});

effect.activeRenderer; // 'webgl' or 'css'
effect.anchoredCount;  // discs sitting on a detected highlight

// After a video seeks, or the artwork behind it changes.
effect.resample();

// Later — on unmount, route change, or teardown.
effect.destroy();

Every option is documented in src/effects/bokeh/README.md, including what the CSS renderer gives up.
