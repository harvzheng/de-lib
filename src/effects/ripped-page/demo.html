Ripped Page

The shot on screen is a printed page. It tears across, the fibres let go in bundles, and the two halves hinge off one end of the rip and pull away to reveal the next shot, which settles out of a punch-in behind them. Cut the way a travel edit cuts: the tear holds, snaps, then decelerates.

Scroll to tear

One polyline, used three ways

The rip is generated once as a deterministic polyline: 1D midpoint displacement, because a tear in paper is self-similar — every scale of the edge looks like the scale above it. That one line becomes a clip-path polygon on each half, the d of the stroked path that paints the fibre edge, and the shadow the torn edge casts into the gap. Nothing is regenerated while you scroll: each frame writes only transforms.

The two shots

Usage

import './effects/ripped-page/effect.css';
import { createRippedPage } from './effects/ripped-page';

// The host is the scroll length; the effect pins the picture inside it.
const rip = createRippedPage(document.querySelector('#rip'), {
  from: '/media/shot-a.jpg',
  to: '/media/shot-c.jpg',
  axis: 'horizontal',
  angle: -7,
  roughness: 0.55,
  fiber: 0.5,
  separation: 0.85,
  hold: 0.12,
});

// Drive it yourself instead of by scroll.
rip.setOptions({ scroll: false });
rip.setProgress(0.5);

rip.destroy();

Every option is documented in src/effects/ripped-page/README.md.
