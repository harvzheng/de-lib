Subway Motion

The host stays the subject. This effect adds the darkness, passing light, glass reflection, and heavy lateral rhythm of a night train to markup you already own. Switch perspective to move from inside the carriage to the platform edge.

Drop it over existing markup

Import the stylesheet once, then pass any positioned or unpositioned host to the factory. The runtime promotes a static host to a positioning context without replacing its content. 

import './effects/subway-motion/effect.css';
import { createSubwayMotion } from './effects/subway-motion';

const effect = createSubwayMotion(host, {
  perspective: 'window',
  speed: 1,
  intensity: 0.8,
  rain: 0.25,
});

// Switch perspective without rebuilding the host.
effect.setOptions({ perspective: 'platform' });

// Later — on unmount, route change, or teardown.
effect.destroy();
