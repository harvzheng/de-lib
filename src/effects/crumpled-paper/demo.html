Crumpled Paper

Whatever is in the host ends up looking printed on a sheet that was screwed up in a fist and flattened out again: straight creases, soft panels between them catching the light at different angles, fibre grain, and the darkening left where the sheet never went flat. The creases are real shading, not a texture image — a height map lit by a distant light — so the whole sheet turns when you move the light instead of pretending to.

Notes from the field

Paper does not crease evenly, and it does not crease in curves. A crumpled sheet is made of straight creases of finite length, with soft panels between them that never went flat again. This effect builds exactly that — creases and panels as shapes, summed into a height map — because noise cannot produce a straight line, and a sheet without straight lines reads as stucco no matter how it is lit.

Everything under here is a normal document — headings, paragraphs, an image with its own grade. The sheet is five composited layers above it, and the content itself is dragged a few pixels along the creases so the print goes over the ridges rather than floating above them.

Usage

import './effects/crumpled-paper/effect.css';
import { createCrumpledPaper } from './effects/crumpled-paper';

const paper = createCrumpledPaper(host, {
  scale: 240,      // px across a panel
  depth: 0.6,
  creases: 0.65,   // creases against soft panels
  light: 135,      // degrees, clockwise from the left
  shine: 0.3,
  warp: 2,         // px the content is dragged along the creases
});

// Let the sheet catch the light as the reader scrolls.
paper.setOptions({ lightShift: 60 });

// Later — on unmount, route change, or teardown.
paper.destroy();

Every option is documented in src/effects/crumpled-paper/README.md, including what `warp` does to the host element.
