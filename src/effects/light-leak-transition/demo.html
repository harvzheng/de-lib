Transition

Light leak transition

A red-orange film fog rolls in from the frame edge, catches the outgoing shot's highlights, and carries the cut inside the flare. Nothing here is pre-rendered: the leak is generated live, either as a fragment shader or as blurred CSS gradients blended over both shots through SVG filters.

Scroll into the leak

One flare, two cuts

The live style is flash, rendering with …. Flash hides the shot swap inside a near-white overexposure. Sweep keeps both shots readable while three warm bands crossfade the incoming frame underneath. Both return to an untouched shot at either end, in either renderer.

The two shots

Usage

import './effects/light-leak-transition/effect.css';
import { createLightLeakTransition } from './effects/light-leak-transition';

const leak = createLightLeakTransition(document.querySelector('#light-leak'), {
  from: '/media/shot-a.jpg',
  to: '/media/shot-c.jpg',
  style: 'flash',
  direction: 'left',
  intensity: 0.85,
  bloom: 0.7,
  warmth: 0.5,
  softness: 80,
  organic: 0.4,
  halation: 0.45,
  grain: 0.3,
  seed: 1,
});

leak.setOptions({ style: 'sweep', direction: 'right' });

// Drive it yourself instead of by scroll.
leak.setOptions({ scroll: false });
leak.setProgress(0.5);

leak.destroy();

Every option and default is documented in src/effects/light-leak-transition/README.md.
