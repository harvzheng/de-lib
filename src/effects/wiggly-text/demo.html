Type that will not sit still

A hand redrawing the same line never draws it twice the same way. This displaces the pixels the text already painted, so it knows nothing about fonts, glyphs or strings — and the text underneath stays real: selectable, searchable and readable by a screen reader.

Font-agnostic by construction

Every specimen below carries the same effect at the same settings. Nothing was measured, split into characters or wrapped in a <span>. Try selecting the text, or find it with your browser's search.

Body copy at 15px

Amplitude is a pixel count, not a fraction of the font size, so one setting that reads as a lively wobble on a headline reads as a broken printer on body copy. Small text wants a smaller amplitude and a shorter wavelength — and at this size the tearing that amplitude causes on thin stems is the limit worth watching.

Drive it yourself

Frame on screen now: 0. A boil is a short cycle of drawings, not a new random field every step — three repeating drawings read as a human redrawing a line, an endless sequence of fresh ones reads as television static. 

import { createWigglyText } from './effects/wiggly-text';

const wiggle = createWigglyText(heading, {
  amplitude: 2,     // px of peak excursion
  wavelength: 90,   // px between wobbles
  boil: 8,          // redraws per second; 0 holds one frame
  frames: 3,        // drawings in the cycle
});

// Later — on unmount, route change, or teardown
wiggle.destroy();

Every option is documented in src/effects/wiggly-text/README.md, including what it does to small text.
